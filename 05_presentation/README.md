# Пункт 5: Презентация решения и материалы к защите

В данном каталоге собраны презентационные материалы команды для финальной защиты решения кейса MTS MWS CompactFactExtraction на хакатоне Innopolis Global Hack 2026.

---

## Содержимое каталога

1. **VIRA_защита.pptx** — итоговая командная слайд-презентация для очной защиты перед экспертным жюри. Включает постановку проблемы, результаты замеров по Парето, демонстрацию экономии GPU-секунд (8.5x) и архитектурную схему.
2. **CompactFact_MWS_Final_Presentation.pptx** — слайд-дек в фирменном стиле с графиками Парето, таблицами метрик и детальным описанием гипотез H1–H5.
3. **speaker_notes.md** — структурированный конспект выступления (спикер-ноты) с таймингом на 5–7 минут защиты, акцентами на ключевых преимуществах и ответами на возможные вопросы жюри.
