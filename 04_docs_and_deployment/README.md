# Пункт 4: Документация архитектуры и руководства по развёртыванию

В данном каталоге представлена детальная инженерная документация по архитектуре решения и инструкциям по его промышленному развертыванию.

---

## Содержимое каталога

1. **architecture.md** — подробное описание архитектуры Two-Stage Compact Neural-Symbolic Extraction с Mermaid-схемой конвейера обработки, описанием слоев LoRA-адаптера и принципов работы Invariant Calibration Engine v3.0.
2. **deployment_guide.md** — пошаговое руководство по развертыванию решения:
   - Минимальные и рекомендуемые системные требования (CPU / GPU).
   - Локальная установка и запуск в изолированном Python venv.
   - Сборка и эксплуатация Docker-образа и запуск через Docker Compose.
   - Манифесты развертывания в кластере Kubernetes (Deployment, Service).
