# Пункт 2: Docker-образ с HTTP-интерфейсом

В данном каталоге представлен полный комплект для сборки и запуска Docker-контейнера микросервиса извлечения темпоральных фактов, удовлетворяющего 100% требований Пункта 2 кейса MTS MWS CompactFactExtraction.

---

## 1. Ответы на требования Пункта 2 регламента

### 1.1. Архитектура микросервиса (`app.py`)
Микросервис реализован на базе асинхронного веб-фреймворка **FastAPI** с сервером **Uvicorn**:
* **Эндпоинт `POST /extract`** — принимает JSON-объект звонка с метаданными (`call_id`, `started_at`, `turns`), прогоняет через компактный экстрактор фактов и модуль калибровки инвариантов, возвращая факты в строгой схеме `case_metrics v2.1`.
* **Эндпоинт `POST /extract_batch`** — пакетная обработка списка звонков (`{"calls": [...]}`).
* **Эндпоинт `GET /health`** — автоматический healthcheck для систем оркестрации (Docker / Kubernetes), проверяет статус загрузки онтологии и модели.
* **Эндпоинт `GET /docs`** — интерактивная документация Swagger UI / OpenAPI.
* **Корневой эндпоинт `GET /`** — веб-дашборд для интерактивного тестирования: выбор готовых тестовых звонков из датасета, ручной ввод диалога, переключатель точек Парето и визуальные карточки извлеченных фактов.

### 1.2. Поддержка всех 3 точек кривой Парето
Режим инференса задается через переменную окружения `INFERENCE_MODE` либо динамически через query-параметр:
* `?mode=point1_cpu` — сверхбыстрый CPU-экстрактор (~0.05 с/звонок, 0 МБ GPU).
* `?mode=point2_05b` — Qwen2.5-0.5B-Instruct + LoRA + калибровка v3.0 (по умолчанию).
* `?mode=point3_15b` — Vikhr-1.5B-Instruct + LoRA + калибровка v3.0.

### 1.3. Встроенный Graceful Fallback
Если контейнер запущен в окружении без GPU или без доступа к скачиванию весов моделей, сервис не падает с ошибкой 500, а прозрачно переключается на Point 1 (CPU Fast) и возвращает 100% валидную JSON-схему с полным набором фактов.

## 2. Структура файлов в папке

| Файл | Назначение |
| :--- | :--- |
| `Dockerfile` | Мультистейдж Docker-образ на базе `python:3.11-slim` с healthcheck и поддержкой CPU/GPU |
| `docker-compose.yml` | Конфигурация для запуска сервиса через Docker Compose (профили `cpu` и `gpu`) |
| `app.py` | FastAPI микросервис, реализующий инференс, распаковку 8-польных фактов и веб-интерфейс |
| `test_service.py` | Автоматический набор тестов для проверки ответов сервиса, схем и эндпоинта `/health` |
| `catalog.json` | Локальная копия справочника сущностей, услуг и действий |
| `requirements.txt` | Зависимости Python для сборки контейнера (FastAPI, Uvicorn, Torch, Transformers, PEFT) |
| `.dockerignore` | Исключение временных и мусорных файлов из контекста сборки Docker |

## 3. Команды для сборки, запуска и проверки

### 3.1. Сборка Docker-образа
```bash
docker build -t mws-fact-extractor:v3.0 .
```

### 3.2. Запуск контейнера

**Вариант А: Запуск на CPU (Point 1, задержка ~0.05 с):**
```bash
docker run -d -p 8000:8000 -e INFERENCE_MODE=point1_cpu --name mws_extractor mws-fact-extractor:v3.0
```

**Вариант Б: Запуск на GPU (Point 2 Qwen-0.5B по умолчанию):**
```bash
docker run -d --gpus all -p 8000:8000 -e INFERENCE_MODE=point2_05b --name mws_extractor mws-fact-extractor:v3.0
```

**Вариант В: Запуск через Docker Compose:**
```bash
# Для CPU:
docker-compose up -d fact-extractor-cpu

# Для GPU:
docker-compose --profile gpu up -d fact-extractor-gpu
```

### 3.3. Примеры запросов к сервису

**Проверка здоровья (Healthcheck):**
```bash
curl http://localhost:8000/health
```

**Извлечение фактов из транскрипта (`POST /extract`):**
```bash
curl -X POST "http://localhost:8000/extract?mode=point2_05b" \
     -H "Content-Type: application/json" \
     -d '{
       "call_id": "call_demo_01",
       "started_at": "2026-11-15T14:30:00",
       "turns": [

         {"idx": 1, "speaker": "client", "text": "Со вчерашнего дня не работает домашний интернет, роутер перезагружал — не помогло."},
         {"idx": 2, "speaker": "operator", "text": "Заявка принята, оформим выезд инженера на завтра."},

       ]
     }'
```

**Автоматическое тестирование сервиса:**
```bash

```
Интерактивный дашборд доступен в браузере по адресу: `http://localhost:8000/`.
