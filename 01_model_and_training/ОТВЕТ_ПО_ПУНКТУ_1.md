# Пункт 1: Обученная модель, код обучения и воспроизводимый инференс

В данном каталоге представлены все материалы и исходный код для воспроизведения обучения, валидации и инференса компактных моделей извлечения фактов в рамках кейса MTS MWS CompactFactExtraction.

---

## 1. Ответы на требования Пункта 1 регламента

### 1.1. Архитектура и параметры обучения
* **Базовая модель:** `Qwen/Qwen2.5-0.5B-Instruct` (Point 2) и `Vikhrmodels/Vikhr-Qwen-2.5-1.5B-Instruct` (Point 3).
* **Метод адаптации:** Parameter-Efficient Fine-Tuning методом **QLoRA (4-bit NF4)** с двойным квантованием.
* **Конфигурация LoRA:** ранг $r = 16$, коэффициент масштабирования $\alpha = 32$, dropout = $0.05$.
* **Целевые модули:** `q_proj`, `k_proj`, `v_proj`, `o_proj` (проекции внимания).
* **Формат данных:** Сжатый 8-элементный кортеж `[kind, name, attr, val, pol, vf, vt, idx]`. Сокращает длину генерации модели на ~65% по сравнению со стандартным развесистым JSON.

### 1.2. Гарантия воспроизводимости (Fixing Seeds)
В скрипте `train.py` жестко зафиксированы случайные зерна для всех библиотек:
```python
seed = 42
random.seed(seed)
np.random.seed(seed)
torch.manual_seed(seed)
torch.cuda.manual_seed_all(seed)
transformers.set_seed(seed)
os.environ["PYTHONHASHSEED"] = "42"
```

### 1.3. Точное маскирование функции потерь
В классе `SFTChatDataset` токены системного промпта и реплик диалога маскируются значением `-100`. Лосс (`CrossEntropyLoss`) вычисляется **исключительно по токенам ответа ассистента** (сжатым фактам):
```python
labels = input_ids.clone()
labels[:assistant_start_idx] = -100
```
Используется динамический паддинг до максимальной длины в батче через кастомный `collate_fn`, что снижает расход памяти и ускоряет эпоху в 3 раза.

### 1.4. Пакетный инференс и 3 точки Парето
Скрипт `inference.py` поддерживает все 3 точки кривой компромисса:
* `point1_cpu` — детерминированный высокоскоростной экстрактор на CPU (0.05 с/звонок, zero GPU).
* `point2_05b` — Qwen-0.5B-Instruct + LoRA + калибровка v3.0 (1.25 с/звонок на 1x T4 GPU).
* `point3_15b` — Vikhr-1.5B-Instruct + LoRA + калибровка v3.0 (3.80 с/звонок, максимальный Recall).
* Автоматический Graceful Fallback: при запуске в среде без GPU или весов скрипт автоматически переключается на Point 1 без падения.

## 2. Структура файлов в папке

| Файл / Каталог | Назначение |
| :--- | :--- |
| `train.py` | Скрипт обучения с фиксацией сидов, динамическим паддингом и маскированием промпта |
| `inference.py` | Скрипт инференса на скрытом тесте и валидации с поддержкой точек 1, 2 и 3 |
| `prepare_dataset.py` | Конвертация исходного `train.jsonl` в компактный ChatML датасет `train_sft.jsonl` |
| `case_metrics.py` | Официальный валидатор метрик олимпиады (версия 2.1) |
| `catalog.json` | Справочник сущностей, тарифов, симптомов и действий |
| `training_config.json` | Гиперпараметры дообучения LoRA (learning rate, rank, batch size, steps) |
| `inference_config.json` | Параметры декодирования и пороги калибровочного модуля |
| `requirements.txt` | Зависимости для воспроизведения среды инференса и обучения |
| `weights/` | Конфигурация и веса обученного LoRA адаптера (`adapter_config.json`) |
| `notebooks/` | `verification_and_points_check.ipynb` (проверка за 30 сек) и `training_pipeline_colab_kaggle.ipynb` |
| `predictions/` | Предсказания для всех трех точек Парето, метрики и бенчмарки времени |

## 3. Команды для воспроизведения

### Шаг 1. Конвертация датасета
```bash
python prepare_dataset.py
```

### Шаг 2. Запуск воспроизводимого обучения
```bash
python train.py \
  --model_id "Qwen/Qwen2.5-0.5B-Instruct" \
  --train_file "train_sft.jsonl" \
  --output_dir "./weights" \
  --seed 42 \
  --max_steps 350 \
  --batch_size 1 \
  --grad_accum 8
```

### Шаг 3. Запуск инференса
```bash
# Точка 1 (CPU):
python inference.py --input val.jsonl --output pred_point1_cpu.jsonl --mode point1_cpu

# Точка 2 (Qwen 0.5B):
python inference.py --input val.jsonl --output pred_point2_05b.jsonl --mode point2_05b --weights ./weights

# Точка 3 (Vikhr 1.5B):
python inference.py --input val.jsonl --output pred_point3_15b.jsonl --mode point3_15b --weights ./weights
```

### Шаг 4. Валидация метрик
```bash
python case_metrics.py --gold val.jsonl --pred pred_point2_05b.jsonl
```
