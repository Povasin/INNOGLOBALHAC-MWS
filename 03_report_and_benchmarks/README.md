# Пункт 3: Технический отчёт, кривая Парето и анализ ошибок

В данном каталоге собраны все материалы, подтверждающие выполнение требований по кривой компромисса «Ресурсы × Качество» и глубокий инженерный анализ краевых случаев кейса MTS MWS CompactFactExtraction.

---

## Содержимое каталога

1. **Технический отчёт.pdf** — официальный итоговый технический отчет команды с выводами, обоснованием архитектурных решений, методикой обучения и замерами ресурсов.
2. **03_report_resources_quality_and_error_analysis.pdf** — дополнительный расширенный технический отчет с графиками Парето и детальным разбором распределения ошибок по классам и атрибутам.
3. **report.md** — текстовая версия инженерного отчета с подробными таблицами метрик на валидационном датасете (383 звонка).
4. **error_analysis.md** — детальный разбор ошибок базовой модели и описание пяти гипотез детерминированной калибровки (H1–H5), позволивших поднять Grounding Span до 0.9697–1.0000 и устранить расхождения с каталогом.
5. **pareto_curve_data.json** — структурированные числовые замеры времени инференса, утилизации VRAM/RAM и метрик качества для всех трех исследованных точек решения.
